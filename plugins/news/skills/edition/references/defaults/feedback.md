# Newspaper feedback

Write what you want changed under `## Open`, one bullet each, in any words.
Every morning's edition reads this note before it gathers anything, turns each
item into a change to `config/topics.yaml` or `config/design.yaml`, and moves
it under `## Applied` with the date and what changed. An item it cannot read
stays under `## Open` with a question under it; answer the question in place.

Each story in the paper shows a small id such as `#2026-10-07-evals-02`. Use it
to point at a story:

- more like #2026-10-07-evals-02
- less like #2026-10-07-allianz-03
- source GNZ is paywalled, prefer MKK-Echo
- add Bruchköbel to the local section
- shorter Deloitte stories
