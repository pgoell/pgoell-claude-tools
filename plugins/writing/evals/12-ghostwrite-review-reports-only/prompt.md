# Write the first draft yourself

Write the first draft yourself, even if it's worse.

For a while I let an AI tool write my first drafts. The posts came out clean and fast, and they sounded like everyone else's. A colleague read my last one and said it read like a press release. That stung because she was right.

Now I start by dictating a messy voice memo. I talk through the idea the way I would explain it to someone at lunch, then I clean up the transcript myself. It is slower at first. The upside is that I remember what I wrote, and I can defend every sentence in it.

This is not an argument against AI. I still let it write my READMEs, where nobody cares whether the prose sounds like me. For anything with "I" in it, the first draft is mine.
