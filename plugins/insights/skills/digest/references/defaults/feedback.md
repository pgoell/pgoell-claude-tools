# Insights feedback

Write what you want the insights job to do differently under `## Open`, one
bullet each, in any words. Lines you start with `no:` in a day's review note
land here too, with their problem id. Every morning's run reads this note
first, turns each item into a standing rule in `memory/rules.md` or a verdict
on a problem, and moves it under `## Applied` with the date and what changed.

Items can be as short as "no todos for missing tools, I install them myself"
or "stop showing the chrome lock".
