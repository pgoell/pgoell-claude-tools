Implementation Plan

Comment threads on task cards

For agentic workers: use deprecated:test-driven-development. Steps use <span class="checkbox"> for tracking.

Date: 2026-05-08 Owner: Pascal Goellner Draft Source spec

Summary

Goal
Let collaborators comment on a task card without leaving the board.
Architecture
A comments table keyed by task_id, served by a Fastify route.
Tech stack
Node 20, Fastify, Postgres 16, Vitest.

Design

Problem
Task discussion happens in chat and gets lost.
Chosen approach
A flat comment list on each task card.
Key decisions
No nested replies.
Out of scope
Notifications, reactions.

  1. Implement encodeCursor.

    tricky-kernel The (created_at, id) tiebreak order is the design.

    const encodeCursor = (c: Comment): string =>
  btoa(`${c.created_at.toISOString()}|${c.id}`);

  2. Run the test.

    npm test -- cursor
    Expected: PASS.

  3. Commit.
