# Preset showcase: technical

Engineers presenting to engineers: architecture reviews, design docs presented live, engineering deep dives, incident reviews, and platform or data-engineering talks. The audience reads diagrams and code closely, so the slides are dense by design.

19 example slides, rendered at 1920x1080 and shown here at 1280x720. The HTML sources live in [`slides/`](slides/); provenance and coverage in [`manifest.md`](manifest.md). All copy is fictional placeholder content.
