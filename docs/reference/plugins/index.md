# Plugins

One page per plugin in the marketplace, in marketplace order. Each page names the plugin's skills (or its styles or hooks), the runtimes it ships to, where its source lives, and what setup it needs.

- [atlassian](/reference/plugins/atlassian.md): Jira and Confluence for Atlassian Cloud
- [google-workspace](/reference/plugins/google-workspace.md): Gmail and Calendar through the `gws` CLI
- [research](/reference/plugins/research.md): research a topic and write a sourced report
- [writing](/reference/plugins/writing.md): a ghostwriter that drafts for you and a coach that teaches you to write
- [runtime-bridge](/reference/plugins/runtime-bridge.md): align Claude Code and Codex project files
- [agent-system-management](/reference/plugins/agent-system-management.md): audit instruction files, capture session learnings, build skills
- [terminal](/reference/plugins/terminal.md): drive interactive terminal programs through tmux
- [playground](/reference/plugins/playground.md): single-file HTML playgrounds with controls and live preview
- [databricks](/reference/plugins/databricks.md): Databricks CLI work and live docs lookups
- [learning](/reference/plugins/learning.md): skills that teach you, by quiz, survey and rebuilding a concept
- [critique](/reference/plugins/critique.md): critique an idea from several independent angles
- [presentations](/reference/plugins/presentations.md): design, build, edit and export slide decks, styled by presets
- [diagrams](/reference/plugins/diagrams.md): validated, themeable architecture and workflow diagrams as HTML
- [news](/reference/plugins/news.md): a personal daily newspaper in a kasten vault
- [insights](/reference/plugins/insights.md): daily problems and fixes from your sessions, and what your agents did
- [file-size](/reference/plugins/file-size.md): cap authored files at 5000 tokens on commit, on push and in CI
- [issue-loop](/reference/plugins/issue-loop.md): an unattended build loop over a repo's GitHub issues
- [prose-styles](/reference/plugins/prose-styles.md): four output styles for how the agent writes prose
- [guards](/reference/plugins/guards.md): a hook that blocks shell commands known to fail
- [session-title](/reference/plugins/session-title.md): a hook that names each session after folder, branch and start time
- [ponytail](/reference/plugins/ponytail.md): the simplest code that works, tracked from upstream
- [emil](/reference/plugins/emil.md): Emil Kowalski's design engineering skills, tracked from upstream
- [vercel](/reference/plugins/vercel.md): Vercel's React, Next.js and deploy skills, tracked from upstream
- [taste-skill](/reference/plugins/taste-skill.md): frontend design skills against generic UI, tracked from upstream
- [deprecated](/reference/plugins/deprecated.md): the frozen archive of superseded skills
