# Skills at a glance

Every live skill of this repo's own plugins, in marketplace order. The skills of the four upstream plugins the marketplace points at by git URL (ponytail, emil, taste-skill and vercel) are in [Upstream skills at a glance](/reference/upstream-skills.md). Invoke a skill from the host agent with its full name, `/<plugin>:<skill>`, which works whatever else you have installed. Each plugin's page has more detail.

The agent can also start every skill on its own from a plain request that matches its description; cron types the slash command for `/insights:digest`, `/insights:activity` and `/news:edition`.

## Archived skills

The [deprecated](/reference/plugins/deprecated.md) plugin keeps 24 superseded or retired skills installable so old workflows still resolve: `crafting-presentations`, `perfecting-presentations`, `exporting-decks-to-pptx` and `presentations` point at the presentations plugin; `autopilot`, `copilot`, `dispatching-parallel-agents`, `terse-mode` and the 12 skills of the retired `workbench` plugin retire without replacement; `writing`, `pyramid` and `tech-doc` point at `/writing:ghostwrite` and `/writing:coach`; `frontend-design` points at `/taste-skill:taste-skill` (in Codex, `taste-skill:design-taste-frontend`).

## Plugins without skills

Three plugins ship no skills. [prose-styles](/reference/plugins/prose-styles.md) ships four output styles that govern how the agent writes for a whole session. [guards](/reference/plugins/guards.md) ships a hook that blocks shell commands known to fail, and [session-title](/reference/plugins/session-title.md) ships a hook that names each new session after its folder, branch and start time. See [Plugins without skills](/explanation/plugins-without-skills.md).
