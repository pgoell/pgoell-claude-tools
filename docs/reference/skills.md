# Skills at a glance

Every live skill, in marketplace order. Invoke a skill from the host agent with its full name, `/<plugin>:<skill>`, which works whatever else you have installed. Each plugin's page has more detail. The names are Claude Code's; Codex names most taste-skill skills differently, and [taste-skill](/reference/plugins/taste-skill.md) lists both.

## Archived skills

The [deprecated](/reference/plugins/deprecated.md) plugin keeps twelve superseded skills installable so old workflows still resolve: `crafting-presentations`, `perfecting-presentations`, `exporting-decks-to-pptx` and `presentations` point at the presentations plugin; `autopilot`, `copilot` and `dispatching-parallel-agents` point at `/workbench:pilot` or `/workbench:subagent-driven-development`, and `terse-mode` retires without replacement; `writing`, `pyramid` and `tech-doc` point at `/writing:ghostwrite` and `/writing:coach`; `frontend-design` points at `/taste-skill:taste-skill` (in Codex, `taste-skill:design-taste-frontend`).

## Plugins without skills

Three plugins ship no skills. [prose-styles](/reference/plugins/prose-styles.md) ships four output styles that govern how the agent writes for a whole session. [guards](/reference/plugins/guards.md) ships a hook that blocks shell commands known to fail, and [session-title](/reference/plugins/session-title.md) ships a hook that names each new session after its folder, branch and start time. See [Plugins without skills](/explanation/plugins-without-skills.md).
