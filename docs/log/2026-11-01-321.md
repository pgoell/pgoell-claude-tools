# 2026-11-01: Fix

structure 0.2.2, issue 321, a regression from PR #319. That PR's copy check in `structure-hook` passed every file in silence in two cases: `scripts/` as a symlink out of the repo, and `GIT_DIR` set without `GIT_WORK_TREE`, as when `claude` starts from a git hook in a linked worktree. The hook now also looks for its copy by the path it was called by, and drops the variables git exports, so the file's path alone picks its repo. `GIT_DIR` with `GIT_WORK_TREE` no longer steers it either. The copy in `pgoell/project-template` differs until its next sync. Pages changed: `reference/plugins/structure.md`.
