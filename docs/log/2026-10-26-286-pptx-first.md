# 2026-10-26: Update

presentations 0.8.0 (issue #286): decks now come out as PowerPoint by default. The new `building-pptx-decks` skill builds a structured `.pptx` from a `deck.md` or content (preset colors and fonts in the Office theme, layouts with named placeholders, native charts, speaker notes), fills a client template a local preset keeps under `pptx/`, and edits an existing `.pptx` in place with a shipped standard-library tool and checker. `creating-presentations` is now the HTML route, taken when HTML, a browser deck or the presenter view is asked for. `exporting-presentations-to-pptx` measures the rendered HTML in headless Chrome and writes a structured deck with `pptxgenjs` instead of positioning loose python-pptx boxes. `extracting-presets` keeps a client template and records PowerPoint font tokens. Changed `reference/plugins/presentations.md`, `reference/skills.md`, `how-to/set-up-presentations.md`, `reference/conventions/html-producers-presets-and-themes.md`, `reference/conventions/skill-design-patterns.md` and `explanation/skill-design-patterns.md`.
