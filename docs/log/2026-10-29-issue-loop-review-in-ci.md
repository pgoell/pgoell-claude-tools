# 2026-10-29: Update

issue-loop 0.12.0. A loop can now run on a repo that reviews its PRs in CI. `REVIEW_IN=ci` in `loop.env` lays `assets/rules-ci.md` over rules 7, 15 and 16 of the brief: the implementer answers and resolves CI's review threads, and a PR on a code-owned path ends `HELD #N` while it waits for the owner's approving review. `wait.sh`, `notify.sh` and `gate.sh` know HELD (`GATE HELD`, exit 0). `IMPL_ENV_FILE` loads a file such as a bot account's `GH_TOKEN` into the implementer's session only. Changed pages: [the issue-loop plugin](/reference/plugins/issue-loop.md), [Set up the issue loop](/how-to/set-up-the-issue-loop.md).
