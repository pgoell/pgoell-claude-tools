# 2026-10-20: Update

agent-system-management 0.7.10, issue #236 (part 5 of 5). `plugins/agent-system-management/evals/` gains cases 41 and 42, which test the rule under "Find the behavioral core" in `creating-skills/references/cutting-skills.md`: a line stays only if it serves the trigger list or a decision a capable agent would get wrong without it. Each prompt pastes a `SKILL.md` draft and asks for the cut skill back in full. `creating-skills` must fire and its siblings must not. An `llm` grader checks that a line which fails the rule is gone (general-knowledge advice in 41, history that changes nothing in 42), and another checks that a line which passes it stays (a non-obvious domain constraint in 41, a control on an irreversible action in 42). The graders are `llm`, not regex, because the skill's report table quotes each cut line. Both cases carry the tags `core` and `deletion`. The suite now holds 15 cases; no one has run it yet. `reference/plugins/agent-system-management.md` updates its "Evals" section.
