# 2026-11-01: Fix

structure 0.2.6, issues 334, 335 and 332. `structure-hook` now drops mise's shim folder from `PATH` and calls `mise exec` so that it reads no project's config, so a `path:` tool in the edited repo's mise config no longer runs. A `jq` that only a project's mise config pins no longer serves the hook, which then exits 1 and says so. A failing `jq` and a missing `git` now exit 1 with a message; a file name that ends in a newline or starts with `-` is now checked; stdin left open or without end no longer hangs the hook. The copies in other repos differ until their next sync. Pages changed: `reference/plugins/structure.md`.
