# 2026-10-19: Fix

workbench 1.4.9, issues #245 and #247. Specs and plans now resolve their folder in one order, written once in `config-schema.md`: `.workbench/pilot.md` `## Documentation paths`, `.workbench/config.md` `## Output paths`, the project `CLAUDE.md` or `AGENTS.md` convention, an existing `docs/superpowers/specs` or `docs/superpowers/plans` folder, then `.workbench/specs/` or `.workbench/plans/`. Brainstorm summaries and debug reports keep `## Output paths`, then the default. Every rung gives a folder and the skill appends the file name; `writing-spec`, `writing-plans` and `pilot` point to the schema instead of keeping their own orders. The HTML plan template gains a Design section that holds the medium-lane `## Design` preamble and that the large lane removes, and its sample spec link now ends in `-design.html`. Pages changed: `/reference/conventions/workbench-routing.md`, `/explanation/workbench-routing.md` and `/reference/plugins/workbench.md`.
