# 2026-11-01: Fix

structure 0.2.1, issue 294. `structure-hook` judged an edited file by the git repo it sits in, so a nested repo the project ignores (a vault, a colocated jj repo) got a fan-out message on every edit and loose objects from the throwaway index. The hook now acts only when the file's repo holds a copy of the hook at the same path; anything else passes untouched. It never runs that other copy. A repo with an older copy overwrites it where it sits, by rerunning `/structure:setting-up-the-checks` when the copies are in `scripts/`. Pages changed: `reference/plugins/structure.md`.
