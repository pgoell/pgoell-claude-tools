# 2026-11-01: Fix

structure 0.2.1, issue 294. `structure-hook` judged an edited file by the git repo it sits in, so a nested repo the project ignores (a vault, a colocated jj repo) got a fan-out message on every edit and loose objects from the throwaway index. The hook now acts only when the file's repo holds a copy of the hook at the same path, and runs that copy; anything else passes untouched. A repo with an older copy reruns `/structure:setting-up-the-checks`. Pages changed: `reference/plugins/structure.md`.
