# 2026-10-20: Update

structure 0.2.0, the `file-size` plugin renamed. Its skill `setting-up-the-check` becomes `/structure:setting-up-the-checks` and now also sets up `check-fan-out`, which fails when a folder holds more than 7 entries (a `.fan-out-baseline` absorbs today's overages, `.fan-out-excludes` lists folders that are lists by design), and `structure-hook`, a Claude Code `PostToolUse` hook that runs both checks on each edited file. A new skill `/structure:setting-up-import-boundaries` writes per-repo import-linter and dependency-cruiser rules. This repo now runs the fan-out check on commit and in `mise run lint`, and the hook from `.claude/settings.json`. An install of `file-size@pgoell-claude-tools` must change to `structure@pgoell-claude-tools`. Pages changed: `reference/plugins/structure.md` (was `file-size.md`), `reference/plugins/index.md`, `reference/skills.md`, `reference/runtimes.md`, `reference/conventions/developing-a-skill.md`, `how-to/install-in-cursor.md`, `explanation/repo-conventions.md`.
