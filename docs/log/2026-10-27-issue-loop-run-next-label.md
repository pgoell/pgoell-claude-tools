# 2026-10-27: Update

issue-loop 0.11.0. A repo may have a "run next" label (`priority` on most repos) that the user puts on an issue to move it up the queue. Such issues run after the last task's own faults and leftovers and before the open bugs, oldest first. The label never runs a "not now" issue and skips no gate. Changed `references/queue.md`, `references/setup.md`, the handoff template, `SKILL.md`, the plugin README and `how-to/set-up-the-issue-loop.md`.
