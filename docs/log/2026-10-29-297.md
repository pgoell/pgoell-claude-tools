# 2026-10-29: Update

issue-loop 0.13.0, issue #297. The loop reads issue and PR text only from trusted authors, since anyone can comment on a public repo's issues. `TRUSTED_AUTHORS` in `loop.env` lists them; empty, it is the repo's owner, the account of the token in `IMPL_ENV_FILE`, and with `REVIEW_IN=ci` `github-actions[bot]`. `trusted_queue` and `trusted_read` in `lib.sh` give the orchestrator the queue and an issue with untrusted text left unread, `next.sh` refuses a task line that names an issue by anyone else, and rule 2 of the brief hands the implementer `gh api` commands that filter on `.user.login`. A new eval plants an outside login's issue and comment. Changed pages: [the issue-loop plugin](/reference/plugins/issue-loop.md), [Set up the issue loop](/how-to/set-up-the-issue-loop.md).
