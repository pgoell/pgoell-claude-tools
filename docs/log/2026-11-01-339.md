# 2026-11-01: Fix

structure 0.2.8, issue 339. Four faults with odd names. `.fan-out-excludes` takes `[` and `^` as plain characters, and no longer stops `check-fan-out` with an invalid regexp; `[...]` is no longer a class there, so an exclude that used one needs rewriting. `--update-baseline` writes lines it can read: a report and the baseline now write a `#` or space that starts a path as `\#`, `\s`, and a tab or CR as `\t`, `\r`. `pre-commit` and `pre-push` work at a repo top ending in a newline, and so does step 1 of `setting-up-the-checks`. `check-file-size` writes names the same way, and reads `\n`, `\t`, `\r`, `\s` in `.file-size-excludes`, where these once meant plain letters. The copies in other repos differ until their next sync. Pages changed: `reference/plugins/structure.md`.
