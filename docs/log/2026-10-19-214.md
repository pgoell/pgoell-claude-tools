# 2026-10-19: Update

file-size 0.1.0, a new plugin, for issue 214. Its skill `/file-size:setting-up-the-check` sets up the 5000-token cap (bytes/4) in any repo: it copies the script to `scripts/check-file-size` and wires lefthook pre-commit on staged files, pre-push and a CI step on every tracked file, or versioned `.githooks/` for a repo without lefthook or mise. The script keeps generic default excludes, and a repo adds its own in `.file-size-excludes`. This repo now runs the plugin's script through `mise-tasks/check-file-size`, with its own excludes in `.file-size-excludes`, and the test moved to `plugins/file-size/tests/run.sh`. New page `reference/plugins/file-size.md`; changed `reference/plugins/index.md`, `reference/skills.md`, `reference/runtimes.md`, `how-to/install-in-cursor.md`, `tutorials/getting-started.md`, `explanation/repo-conventions.md` and `reference/conventions/developing-a-skill.md`.
