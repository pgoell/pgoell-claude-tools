# 2026-11-01: Fix

structure 0.2.3, issue 324. `structure-hook` said it never ran code from the repo of an edited file, but its `git add` and the checks' `git ls-files` obeyed that repo's config: `core.fsmonitor`, `filter.*`, hooks, `pager.*` and a partial clone's lazy fetch all ran commands. The hook now runs them against a throwaway git dir, with the repo as the work tree. Settings in the repo's own config (a filter, `core.excludesFile`, `core.autocrlf`) and `includeIf "gitdir:..."` in the global config no longer apply. A tracked file that `.gitignore` also matches now passes, and the hook's fan-out count skips tracked entries not on disk. A file named `--update-baseline` or `--all` no longer switches `check-fan-out` to that mode. The copy in `pgoell/project-template` differs until its next sync. Pages changed: `reference/plugins/structure.md`.
