# Directory Update Log

The log of changes to this bundle is one file per change, in the `log/` folder next to this page. This page lists no entries, so it does not grow.

Each file is named `YYYY-MM-DD-<slug>.md`: the date of the change, then the issue and PR numbers the change names (`2026-10-19-209-216-217.md`), or a short name for what changed when it names none (`2026-10-18-insights-worktrees.md`). Names are unique. Sorted by name, the newest day comes last.

To log a change, add a new file in `log/`. Start it with an H1 of the date and the kind of change, `# YYYY-MM-DD: Update` or `# YYYY-MM-DD: Fix`, then one paragraph: the plugins and versions it touches, the issue and PR numbers, what changed, and which pages under `docs/` changed. These files carry no frontmatter. Never edit an old entry to log a new change.
