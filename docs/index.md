# pgoell-claude-tools documentation

Documentation for pgoell-claude-tools, a plugin marketplace for Claude Code, Codex and Cursor. The pages are split the way [Diátaxis](https://diataxis.fr) splits them, and the files follow the [Open Knowledge Format](https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/main/okf/SPEC.md) v0.2, so an agent can walk this directory without being told how.

Each page carries a `type` in its frontmatter, and that type is the Diátaxis quadrant: `Tutorial`, `How-to Guide`, `Reference` or `Explanation`. Read the quadrant that fits what you are doing. Learning comes first, doing second, looking things up third, understanding last.

## Quadrants

- [Tutorials](/tutorials/index.md): a first lesson that installs the marketplace and runs a skill
- [How-to guides](/how-to/index.md): setup for the plugins that need it, and recipes for installing and updating
- [Reference](/reference/index.md): one page per plugin, every skill at a glance, and which runtime gets which plugin
- [Explanation](/explanation/index.md): why the marketplace is built the way it is
