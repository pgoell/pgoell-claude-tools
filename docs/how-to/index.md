# How-to guides

Recipes for jobs you already know you need. Each one assumes you have added the marketplace; if you have not, start with [Getting started](/tutorials/getting-started.md). Plugins not listed here need nothing beyond install.

- [Install in Cursor](/how-to/install-in-cursor.md): install plugins from the Cursor Marketplace, a team marketplace, or a local copy
- [Update plugins](/how-to/update-plugins.md): pull new plugin versions into Claude Code, Codex or Cursor
- [Set up the atlassian plugin](/how-to/set-up-atlassian.md): an API token for Jira and Confluence, and the optional Atlassian CLI
- [Set up the google-workspace plugin](/how-to/set-up-google-workspace.md): install and log in to the `gws` CLI for Gmail and Calendar
- [Set up the databricks plugin](/how-to/set-up-databricks.md): install the Databricks CLI and add an OAuth profile
- [Set up the terminal plugin](/how-to/set-up-terminal.md): install tmux on Linux, macOS or WSL
- [Set up the presentations plugin](/how-to/set-up-presentations.md): the tools each skill uses, and a project preset in `.pgoell/presentations/`
- [Set up the diagrams plugin](/how-to/set-up-diagrams.md): Node and a Chromium browser for the engine, and a project theme in `.pgoell/diagrams/`
- [Schedule the newspaper](/how-to/schedule-the-newspaper.md): a cron line that builds the daily edition in your kasten vault
- [Schedule insights](/how-to/schedule-insights.md): cron lines for the daily digest and activity pages
- [Set up the issue loop](/how-to/set-up-the-issue-loop.md): what the repository and host need, the loop folder, and your standing order
- [Pick an output style](/how-to/pick-an-output-style.md): turn on a `prose-styles` style in Claude Code, and turn it off
- [Set up ponytail](/how-to/set-up-ponytail.md): install the external plugin, what its hooks do, and how to set or stop its mode
- [Set up the vercel plugin](/how-to/set-up-vercel.md): network access for the guideline skills and the Vercel CLI for deploys
- [Move from autopilot or copilot to workbench pilot](/how-to/move-to-workbench-pilot.md): rename the profile and set the `Gates:` row
